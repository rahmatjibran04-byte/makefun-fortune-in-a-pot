## Entry

**"Your leaves will outgrow this windowsill — the sun already has plans for you, and the watering can agrees."**

One line of fortune (108 characters, within the 120-character limit) for a
houseplant on a windowsill: the leaves outgrow their sill, the sun has plans,
and even the watering can agrees. Optimistic, a little whimsical, and it reads
like something the plant itself would want to hear.

## How it works

`main.py` (Python 3.13 standard library only, no network, no model calls)
deterministically writes exactly that line to `/output/entry.txt` — no
trailing newline — and sets the file mode to `0644` so the grader can read it.

## Run

```sh
python3 main.py
# or: ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
